# Homepage concepts

Playable prototypes explored for the narnelabs.com homepage. This branch is not deployed.

| File | Concept |
|------|---------|
| `town.html` | Narne Town: isometric town, one building per app (shipped to main) |
| `knot.html` | The Knot: pull the rope onto the hook, apps hang on the line (fallback choice) |
| `device.html` | The Device: hardware gadget with keys, dial and dot-matrix screen |
| `board.html` | Split-flap departures board |
| `shadow-theatre.html`, `catalogue.html` | Earlier static directions |

To preview: `python -m http.server 8000` from the repo root, then open `/concepts/<file>`.
