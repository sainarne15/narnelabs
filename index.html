[04] Process

          
How an idea
becomes an app.

        

        

          
01
Spark
Every app starts with something that annoyed us: a real problem real people have.

          
02
Prototype
We build the smallest version that could work, then put it in people's hands right away.

          
03
Engineer
We make it fast, private and reliable. If it can run on your device, it does.

          
04
Launch
It ships on the web, on Google Play, or both, and it's free whenever we can manage it.

          
05
Evolve
We listen, iterate and improve. A product is never really finished.
